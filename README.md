# Gram Vikas Portal

MASTER PROMPT — PREMIUM GRAM PANCHAYAT DIGITAL PLATFORM

Redesign and rebuild the attached/reference Gram Panchayat website into a high-end, modern, accessible, responsive digital platform for a Gram Panchayat in Maharashtra, India.

The existing/reference design feels outdated, cluttered, overly governmental, and visually inconsistent. Completely modernize the UI/UX while preserving every important piece of content, functionality, section, information category, and feature described in the reference PDF.

The final website should feel like a combination of:

A premium Indian government digital service portal

A modern civic-tech platform

A trustworthy community information portal

A sophisticated SaaS dashboard

A beautiful village/community showcase

Do NOT make it look like a generic corporate website.

The website must communicate:

Trust + Transparency + Community + Development + Accessibility + Technology + Indian Village Identity
